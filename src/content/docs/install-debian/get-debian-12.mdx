### Download

1. Download Debian GNU/Linux 12 bookworm ( released on 10 June, 2023 ) from the following site.

   - [http://cdimage.debian.org/debian-cd/](http://cdimage.debian.org/debian-cd/)

### Create an installation CD/DVD

2. After downloading ISO of Debian, Burn it to a DVD with an burning application to create an installation disk.  
   If you create it with the feature of Windows 10/11, refer to follows.

## ![](https://www.server-world.info/en/Debian_12/download/img/1.png)

3. Insert an empty DVD media in DVD drive. Next, right-click the ISO image of Debian and select `Burn Disk image` in the menu.

Click the `Burn` button and start burning.  
After finishing it, eject the disk and [proceed to the installation step](https://www.server-world.info/en/note?os=Debian_12&p=install).
