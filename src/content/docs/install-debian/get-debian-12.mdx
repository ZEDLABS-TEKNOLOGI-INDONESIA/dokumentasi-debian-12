### Download

<Steps>

1. Download Debian GNU/Linux 12 bookworm (released on 10 June, 2023) from the following site.
   [debian-12.12.0-amd64-DVD-1.iso](https://cdimage.debian.org/cdimage/archive/12.12.0/amd64/iso-dvd/debian-12.12.0-amd64-DVD-1.iso)

</Steps>

### Create an installation CD/DVD

After downloading ISO of Debian, Burn it to a DVD with an burning application to create an installation disk.  
If you create it with the feature of Windows 10/11, refer to follows.

<Steps>
2. Insert an empty DVD media in DVD drive.
   Next, right-click the ISO image of Debian and select `Burn Disk image` in the menu.
   ![](https://www.server-world.info/en/Debian_12/download/img/1.png)

3. Click the `Burn` button and start burning.
   After finishing it, eject the disk and [proceed to the installation step](https://www.server-world.info/en/note?os=Debian_12&p=install).
   ![](https://www.server-world.info/en/Debian_12/download/img/2.png)

</Steps>
