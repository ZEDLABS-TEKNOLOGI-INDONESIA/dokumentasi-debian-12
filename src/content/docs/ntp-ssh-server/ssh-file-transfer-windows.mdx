It's possible to transfer files via SSH on Windows Client.  
On this example, it shows WinSCP (winscp.net/eng/download.php) for it.

If you are using Windows, OpenSSH Client has been implemented as an Windows feature [like here \[7\]](https://www.server-world.info/en/note?os=Debian_12&p=ssh&f=1), so it's possible to use \[scp\], \[sftp\] commands [like the examples here](https://www.server-world.info/en/note?os=Debian_12&p=ssh&f=2).

\[1\]

Install and start WinSCP, then following initial windows is displayed. Input Hostname, Username and User's Password and then Click \[Login\] button.

![](https://www.server-world.info/en/Debian_12/ssh/img/4.png)

\[2\]

After successing authentication, it's possible to transfer files on WinSCP via SSH.

![](https://www.server-world.info/en/Debian_12/ssh/img/5.png)
