Configure SSH Server to manage a server from the remote computer. SSH uses 22/TCP.

1.  Password Authentication for OpenSSH Server on Debian is enabled by default, so it's possible to login without changing any settings. Furthermore, root account is prohibited Password Authentication by default with \[PermitRootLogin prohibit-password\], so default setting is good for use. But if you prohibit root login all, change like follows.

root@dlp:~#

[apt](https://www.server-world.info/en/note?p=command&q=apt) -y install openssh-server

root@dlp:~#

[vi](https://www.server-world.info/en/note?p=command&q=vi) /etc/ssh/sshd_config

\# line 33 : uncomment and change to \[no\]

PermitRootLogin

no

root@dlp:~#

[systemctl](https://www.server-world.info/en/note?p=command&q=systemctl) restart ssh

SSH Client : Debian

Configure SSH Client for Debian.

2.  Install SSH Client.

root@client:~#

[apt](https://www.server-world.info/en/note?p=command&q=apt) -y install openssh-client

3.  Connect to the SSH server with a common user.

\# ssh \[username@hostname or IP address\]

SSH Client : Windows#1

Configure SSH Client for Windows.

5.  Get a SSH Client for Windows. This example shows to use [Putty](http://www.chiark.greenend.org.uk/~sgtatham/putty/) like follows.

Input your server's IP address and Click \[Open\] button.

6.  After authentication on SSH server, it's possible to login remotely with SSH.
