---
title: "Use Parallel SSH"
description: "Panduan lengkap instalasi, konfigurasi, dan pengelolaan Debian 12 untuk server dan desktop."
---

Install Parallel SSH to connect to multiple hosts.

\[1\]

Install PSSH.

root@dlp:~#

[apt](https://www.server-world.info/en/note?p=command&q=apt) -y install pssh

\[2\]

This is the basic usage for PSSH.  
This is the case for key-pair authentication without passphrase.  
If passphrase is set in key-pair, [start SSH-Agent first to automate inputting passphrase](https://www.server-world.info/en/note?os=Debian_12&p=ssh&f=6).

\# connect to hosts and execute \[hostname\] command

debian@dlp:~$

parallel-ssh -H "10.0.0.51 10.0.0.52" -i "hostname"

\[1\] 17:28:02 \[SUCCESS\] 10.0.0.51  
node01.srv.world  
\[2\] 17:28:02 \[SUCCESS\] 10.0.0.52  
node02.srv.world

\# it's possible to read host list from a file

debian@dlp:~$

[vi](https://www.server-world.info/en/note?p=command&q=vi) pssh_hosts.txt

\# write hosts per line like follows

debian@10.0.0.51  
debian@10.0.0.52

debian@dlp:~$

parallel-ssh -h pssh_hosts.txt -i "uptime"

\[1\] 19:37:59 \[SUCCESS\] debian@10.0.0.52
19:37:59 up 1:35, 0 users, load average: 0.00, 0.00, 0.00
\[2\] 19:37:59 \[SUCCESS\] debian@10.0.0.51
19:37:59 up 1:35, 0 users, load average: 0.00, 0.00, 0.00

\[3\]

It's possible to connect with password authentication too, but it needs passwords on all hosts are the same one.

debian@dlp:~$

parallel-ssh -h pssh_hosts.txt -A -O PreferredAuthentications=password -i "uname -r"

Warning: do not enter your password if anyone else has superuser  
privileges or access to your account.  
Password:

\# input password

\[1\] 05:27:08 \[SUCCESS\] debian@10.0.0.51  
5.15.0-25-generic  
\[2\] 05:27:08 \[SUCCESS\] debian@10.0.0.52  
5.15.0-25-generic

\[4\]

By the way, PSSH package includes \[parallel-scp\], \[parallel-rsync\], \[parallel-slurp\], \[parallel-nuke\] commands and you can use them with the same usage of pssh.
