title: "Use SSH-FS"
description: "Panduan lengkap instalasi, konfigurasi, dan pengelolaan Debian 12 untuk server dan desktop."
---

It's possible to mount filesystem on another Host via SSH to use SSHFS.

\[1\]

Install fuse-sshfs.

root@dlp:~#

[apt](https://www.server-world.info/en/note?p=command&q=apt) -y install sshfs

\[2\]

It's possible to use by any user.  
For example, \[debian\] user mount \[/home/debian/work\] on \[node01.srv.world\] to local \[~/sshmnt\].

debian@dlp:~$

[mkdir](https://www.server-world.info/en/note?p=command&q=mkdir) ~/sshmnt

\# mount with SSHFS

debian@dlp:~$

sshfs node01.srv.world:/home/debian/work ~/sshmnt

debian@node01.srv.world's password:

\# password of the user

debian@dlp:~$
